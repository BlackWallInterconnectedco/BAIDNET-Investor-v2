# BAIDNET Investor v2

Isolated prototype for the next BAIDNET ecosystem website.

## Prototype v1
- Cinematic black/gold BAIDNET design system
- Three audience paths: Consumers, Businesses, Investors & Partners
- Isolated Three.js globe hero
- Responsive mobile layout
- Existing BAIDNET production site is not modified

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
